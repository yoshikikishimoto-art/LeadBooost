# TalentFlow — 人材紹介 進捗管理（MVP）

人材紹介会社向けに、**キャリアアドバイザーと連携しながら求職者の情報を管理し、流入（TimeRex予約／リファラル）から「予約 → 着座 → 初回面談 → 企業提案 → 選考 → 内定 → 内定承諾 → 入社 → 返金規定クリア」までの一連のフローを管理する**サービスの MVP です。

## フロー

```
【流入】TimeRex予約 / リファラル（LINEグループで日程調整）
   ↓
予約 → 着座 → 初回面談 → 企業提案 → 選考 → 内定 → 内定承諾 → 入社 → 返金規定クリア
```

- **流入経路**: 各求職者に `TimeRex予約` / `リファラル（LINE）` を記録し、絞り込み・内訳集計が可能
- **予約 / 着座**: 予約だけして未来訪の状態を「予約」、来訪を「着座」として分けて管理し、**着座率（No-show）**を可視化

## できること

- **ダッシュボード**: 稼働中の求職者数 / 着座率 / 内定承諾（承諾率）/ 今月の入社 などの KPI、ステージ別ファネル、流入経路の内訳、最近の動き
- **パイプライン（カンバン）**: 予約→着座→初回面談→企業提案→選考→内定→内定承諾→入社→返金規定クリア をドラッグ＆ドロップでステージ移動
- **求職者一覧**: 名前・企業・スキルで検索、ステージ／流入経路／担当アドバイザーで絞り込み
- **求職者詳細**: 流入経路・希望条件・スキルの管理、ステージを1クリックで前後に進める、活動履歴／アドバイザー連携メモのタイムライン
- **アドバイザー管理**: 担当件数・入社実績の把握

## 技術スタック（MVP）

ビルド不要の**静的SPA**で、すぐにリンク確認できる構成です。フレームワーク（Next.js 等）への移行は相手と相談して決めます。

- HTML / CSS / バニラ JavaScript
- データ保存: ブラウザの `localStorage`（ブラウザ内に保存。サーバ不要）
- デザイン: CSS変数によるセマンティックトークンで色/余白/角丸を単一管理

### ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面構造 |
| `styles.css` | デザイントークン＋全スタイル |
| `app.js` | 状態管理・描画・ロジック・サンプルデータ |

### ローカルでの確認

`index.html` をブラウザで直接開くだけで動きます。または簡易サーバ:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

> ⚠️ これは MVP（プロトタイプ）です。データはブラウザ内 localStorage に保存され、サーバ・認証・複数人でのデータ共有は未実装です。本番化の際はバックエンド/DB が必要です。

## 開発の進め方（共同開発ルール）

このリポジトリは `main` を保護し、作業は必ずブランチを切って Pull Request 経由でマージします。

1. 最新を取得する
   ```bash
   git switch main
   git pull
   ```
2. 作業用ブランチを切る（例: `feat/login-form`, `fix/header-bug`）
   ```bash
   git switch -c feat/your-task
   ```
3. コミットして push する
   ```bash
   git add -A
   git commit -m "feat: 何をしたか"
   git push -u origin feat/your-task
   ```
4. GitHub で Pull Request を作成し、相手にレビューを依頼する
5. レビュー承認後に `main` へマージ

### ブランチ命名

| 種類 | プレフィックス | 例 |
| --- | --- | --- |
| 機能追加 | `feat/` | `feat/user-auth` |
| バグ修正 | `fix/` | `fix/login-error` |
| リファクタ | `refactor/` | `refactor/api-client` |
| ドキュメント | `docs/` | `docs/readme` |

### コミットメッセージ

[Conventional Commits](https://www.conventionalcommits.org/) に従います。

```
feat: ログインフォームを追加
fix: ヘッダーの表示崩れを修正
docs: README に開発手順を追記
```
